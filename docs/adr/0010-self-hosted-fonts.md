# ADR-0010 — Self-hosted fonts with computed fallbacks

**Status:** accepted 2026-09-18 · **Spec:** §9, §3 rows 14 and 21 · supersedes the "system stack" option in the spec's not-now table · departs from §9's "swap" on measurement (see Consequences)

## Context
A system font stack costs nothing and can never shift layout, but the design (Claude Design pass, `docs/design/export-review.md`) is carried by Source Serif 4 and Newsreader. Web fonts risk two scorecard rows: weight (row 14) and layout shift on swap (row 21); a font without comma-below Romanian glyphs would silently show cedilla lookalikes.

## Decision
Three static instances (Source Serif 4 Regular and Italic; Newsreader Medium at optical size 36), subset to Latin, Latin Extended-A, U+0218–021B and the site's punctuation, WOFF2, ≤ 100 KB together, served content-hashed and immutable from the same origin, body regular preloaded, `font-display: optional`. Each family has a fallback face — Times New Roman / Liberation Serif — with `size-adjust` and vertical overrides computed from the two font files by `scripts/fontface` (not typed in), so the fallback, when it is what the reader gets, holds the same lines. No weight the files lack is used; `font-synthesis: none` enforces it. `site check` verifies the glyphs and that the CSS embeds the generated rules; `site check --dist` verifies size, preload and presence; the M2 bench confirms CLS stays at zero in Chromium under optional. Both families are pinned from one google/fonts commit; Source Serif 4 is taken from that distribution, which declares no Reserved Font Name, because the OFL forbids a subset from carrying one and Adobe's own release reserves "Source".

## Consequences
The swap was measured before the descriptor was chosen: with the font arriving 600 ms late, `swap` moved paragraphs by a line on most pages (CLS 0.002–0.011 on a phone, 0.055 on the colophon at laptop width) — a metric-matched fallback equalises paragraph width on average, not every line break. With `optional` there is no swap: Chrome holds first paint briefly for the preloaded font, then either uses it or keeps the matched fallback for that page view, and CLS measured 0 on every page. The price is honest: on a slow first visit the reader gets Times or Liberation for that page and the web font from the next page on. Three requests per page for type (two on pages without italics). Android has neither Times nor Liberation, and Safari before 17.4 ignores the override descriptors: those readers see a plain serif on a cold visit — accepted, and measured nowhere. Changing a typeface is `scripts/fonts.sh` plus one paste and a golden refresh.
